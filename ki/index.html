Siebwrite / Mit KI

Mit KI in deiner Handschrift schreiben

Stand: 4. November 2026

Kurz gesagt

Jeder Chatbot kann dir einen Siebwrite-Link geben. Du öffnest ihn, der Text steht in deiner Handschrift da, und mit einem Tipp ist er in GoodNotes. Claude und andere KI-Agenten, die Code ausführen, machen mit dem Siebwrite-Skill gleich die fertige .goodnotes-Datei.

Mit jedem Chatbot: per Link

Schreib deine Bitte an ChatGPT, Claude, Gemini oder einen anderen Chatbot wie immer und häng diesen Satz an:

Gib mir das Ergebnis als Siebwrite-Link: https://siebwrite.de/app/#text= und direkt dahinter der Text, URL-kodiert (Leerzeichen als %20, Zeilenumbrüche als %0A, & als %26). Nur reiner Text, kein Markdown.

Öffne den Link am besten auf dem iPad. Siebwrite zeigt den Text in der Handschrift, die du in diesem Browser geschrieben hast. Ein Tipp auf „Als GoodNotes importieren“, und die Seite liegt in GoodNotes, radierbar wie deine eigene Schrift.

Für eine bestimmte Optik hängt der Chatbot noch etwas an: &hand=cursive für eine fertige Handschrift (oder elegant, quill, print, playful), &paper=grid für kariert, &ink=schwarz für schwarze Tinte. Der Text steht hinter dem #, und diesen Teil schickt dein Browser an keinen Server.

Mit Claude: gleich als Datei

Claude kann mit Skills eigene Werkzeuge ausführen. Mit dem Siebwrite-Skill macht Claude aus seiner Antwort direkt eine .goodnotes-Datei oder ein PDF, ohne Browser dazwischen.

  1. Skill herunterladen: siebwrite-skill.zip (260 KB).
  2. In Claude hochladen. In den Einstellungen von Claude die ZIP-Datei als Skill hinzufügen. Skills laufen nur, wenn Claude Code ausführen darf.
  3. Schreiben lassen, zum Beispiel: „Fass das Kapitel als Lernzettel zusammen und mach daraus eine GoodNotes-Seite in Schreibschrift.“ Claude gibt dir die Datei zum Herunterladen.

Für deine eigene Handschrift tippst du in der App unten auf „Sichern“ und gibst die Datei Handschrift-Profil.json mit in den Chat. Sie liegt dann beim KI-Anbieter, wie jede Datei, die du dort hochlädst. Ohne die Datei nimmt Claude eine der fünf fertigen Handschriften oder gibt dir einen Link.

Für Entwickler: Kommandozeile und MCP

Im selben Paket steckt ein Programm für Node.js ab Version 18, ohne Installation und ohne Netz:

node siebwrite/agent/siebwrite.mjs --text "Liebe Oma, …" --hand cursive

Mit mcp dahinter läuft es als MCP-Server, etwa für Claude Desktop, Claude Code, Cursor oder Codex. Die Werkzeuge heißen create_handwriting (speichert .goodnotes-Dateien oder ein PDF) und handwriting_link (der Link von oben).

{
  "mcpServers": {
    "siebwrite": {
      "command": "node",
      "args": ["/Pfad/zu/siebwrite/agent/siebwrite.mjs", "mcp"],
      "env": { "SIEBWRITE_PROFILE": "/Pfad/zu/Handschrift-Profil.json" }
    }
  }
}

Alle Optionen zeigt --help, den Rest die Anleitung für Agenten.
