# Handschrift

Eigene Buchstaben mit Stift, Finger oder Maus erfassen, Text damit setzen und als echte,
radierbare `.goodnotes`-Datei oder als PDF ausgeben. Eine einzelne HTML-Datei, kein Build.

Seite: https://shinnight1.github.io/handschrift/

Die Handschrift bleibt im Browser (localStorage). Kommt die Seite über einen Übergabe-Link aus
dem claude.ai-Artifact, stehen Profil, Text und Einstellungen komprimiert hinter dem `#` im Link.
Dieser Teil wird nie an den Server geschickt, und die Seite entfernt ihn nach dem Laden aus der
Adresszeile.
