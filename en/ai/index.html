Siebwrite / With AI

Let AI write in your handwriting

Updated: November 4, 2026

In short

Any chatbot can give you a Siebwrite link. You open it, the text appears in your handwriting, and one tap puts it into GoodNotes. Claude and other AI agents that run code make the finished .goodnotes file themselves with the Siebwrite skill.

With any chatbot: a link

Ask ChatGPT, Claude, Gemini or any other chatbot as usual and add this sentence:

Give me the result as a Siebwrite link: https://siebwrite.de/en/app/#text= followed directly by the text, URL-encoded (spaces as %20, line breaks as %0A, & as %26). Plain text only, no Markdown.

Open the link, ideally on your iPad. Siebwrite shows the text in the handwriting you wrote in that browser. Tap “Import into GoodNotes” and the page is in GoodNotes, erasable like your own writing.

For a particular look the chatbot adds a bit more: &hand=cursive for a ready-made handwriting (or elegant, quill, print, playful), &paper=grid for squared paper, &ink=black for black ink. The text sits behind the #, and your browser never sends that part to a server.

With Claude: straight to a file

Claude can run its own tools through skills. With the Siebwrite skill, Claude turns its answer into a .goodnotes file or a PDF directly, no browser in between.

  1. Download the skill: siebwrite-skill.zip (260 KB).
  2. Upload it to Claude. Add the ZIP file as a skill in Claude’s settings. Skills only run when Claude is allowed to execute code.
  3. Ask away, for example: “Summarize the chapter as study notes and make it a GoodNotes page in cursive.” Claude gives you the file to download.

For your own handwriting, tap “Save” at the bottom of the app and add the file Handschrift-Profil.json to the chat. It then sits with the AI provider, like any file you upload there. Without it, Claude uses one of the five ready-made handwritings or gives you a link.

For developers: command line and MCP

The same package holds a program for Node.js 18 or newer, with nothing to install and no network:

node siebwrite/agent/siebwrite.mjs --text "Dear Grandma, …" --lang en

Add mcp and it runs as an MCP server, for Claude Desktop, Claude Code, Cursor, Codex and others. The tools are create_handwriting (saves .goodnotes files or a PDF) and handwriting_link (the link from above).

{
  "mcpServers": {
    "siebwrite": {
      "command": "node",
      "args": ["/path/to/siebwrite/agent/siebwrite.mjs", "mcp"],
      "env": { "SIEBWRITE_PROFILE": "/path/to/Handschrift-Profil.json" }
    }
  }
}

All options: --help, and the guide for agents.
